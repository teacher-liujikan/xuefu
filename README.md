# 學扶考古題 自己來練習

學習扶助篩選測驗考古題的線上練習網站。

- 首頁：https://teacher-liujikan.github.io/xuefu/
- 數學：https://teacher-liujikan.github.io/xuefu/math/
  - 一～六年級，111～115 年，共 750 題（題目與圖依原卷）
  - 依年度整卷線上作答，交卷打 ○／✗，錯題再做一次
  - 老師挑題：依南一／康軒／翰林單元，或依學扶基本學習內容細目；QR code 給學生掃
  - 「線上作答／印成紙本」一鍵切換；線上一次一題，附可手寫的計算紙
  - 匯出 Word／PDF（可附答案）
  - 交卷後錯題顯示逐步詳解（目前三年級 150 題），錯題可再做一次、匯出 PDF／Word，或用 QR code 傳給老師
  - 每個年級一份模擬卷（照考古題命題架構自編，共 150 題，非官方試題）
  - 一、二年級細目依官方「基本學習內容對照表」；三～六年級細目為自行標註
  - 115 年三～六年級官方未公布答案，答案為自行解題
- 國語、英語：製作中

作答紀錄只存在學生自己裝置的瀏覽器（localStorage），不會上傳。

題目來源：教育部國民及學前教育署 學習扶助篩選測驗公告試題，僅供教學練習使用。
